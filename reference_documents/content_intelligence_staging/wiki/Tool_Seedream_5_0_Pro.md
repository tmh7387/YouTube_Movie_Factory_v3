# Seedream 5.0 Pro

ByteDance image model, used in these workflows specifically for **scene plates**
— the empty environment still that anchors a sequence.

## Where it's strong

Cinematic image character. Handles overexposure and halation in a way that reads
as photographed, and that quality carries through when the still is fed to a
video model.

## Where it isn't used

Faces. Reported as not holding facial likeness reliably, so character sheets and
wardrobe go to [[Tool_Nano_Banana_Pro]] instead. The split — environment from
one model, faces from another — is deliberate.
