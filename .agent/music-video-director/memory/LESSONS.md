## 2026-08-14 — Stack audit (pre-production baseline)
What happened: music video output was hit-or-miss across projects.
Root cause: four skills answered the same trigger with conflicting doctrines
(prompt verbosity, sheet formats, model routing), and no memory persisted
between sessions.
Rules extracted: (1) one entry-point skill per domain — retire
seedance-clean and music-video-producer; (2) prompt verbosity follows the
identity carrier (Soul ID → none, image ref → lean 5 anchors, no ref → full
card); (3) memory lives in the repo, and a project is not complete until the
wrap-up commit is written.
